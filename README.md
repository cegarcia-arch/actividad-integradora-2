# Gestor de tareas

Actividad Integradora 2 de Programación de Sistemas Web. Proyecto nuevo, con HTML, CSS y JavaScript Vanilla, para Cesar Leonardo Garcia Macias (Leo).

## Desarrollo por etapas

1. Estructura visual del formulario, resumen y lista.
2. Gestión de tareas y validación en JavaScript.
3. Filtros, búsqueda, ordenamiento y contadores.
4. API y almacenamiento local en módulos ES6.
5. Funcionamiento sin internet y comprobaciones.
6. Evidencias, declaración de IA e informe.

Los commits conservan las fechas reales. Varios commits en un mismo día no eliminan la penalización indicada en la actividad.

## Ejecutar localmente

Desde esta carpeta, ejecutar `python3 -m http.server 8000` y abrir `http://localhost:8000`.
La aplicación usará módulos ES6, por lo que debe abrirse mediante un servidor HTTP, no con doble clic sobre el HTML.
